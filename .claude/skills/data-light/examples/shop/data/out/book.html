반찬가게 주문

데이터 설명서 -- 무엇을 기록하고, 어떤 일에 쓰고, 실제로 어떤 값이 들어가나

이 문서 읽는 법
  • 표는 엑셀 시트 하나, 한 줄은 기록 하나(손님 한 명, 주문 한 건), 칸은 열입니다.
  • 다른 표를 가리키는 칸은 표끼리 잇습니다 -- 예: 주문의 '손님' 칸은 손님 표의 한 줄을 가리킵니다.
  • 개인정보(이름·전화 …)는 짝 표에 따로 둡니다. 본 줄을 지우면 같이 지워집니다.
  • 알고 싶은 것은 이 데이터로 꼭 나와야 하는 답입니다. 검사가 예시 값으로 실제로 돌려 봅니다.
  • 예시 값은 만든 값입니다 (실제 사람이 아닙니다).

확인할 것: 빠진 기록이나 칸이 없나요? 하는 일과 표의 연결이 실제와 같나요? 예시를 보면 이상한 곳이 있나요?

무엇을 만드나

데이터 관리 (찾고·고치기) (함께: 알고 싶은 것 보기 (분석))

사용자가 한 말: “주문을 받아 적어 두고 찾아보고 싶어요. 손님별로 얼마 주문했는지도 보고 싶고요”

이번에 만들지 않을 것: 결제, 배송 추적, 회원 로그인

알고 싶은 것

  1. 손님별 주문 금액 합계를 볼 수 있다
  2. 판매 중인 반찬만 골라 볼 수 있다
  3. 주문 상태별 건수를 셀 수 있다
