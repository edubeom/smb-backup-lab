# 공개본 생성과 검토

운영 원본과 분리한 초기 이력으로 게시했다. docs/inventory.md, 운영 dev-notes 원문, 과거 snapshot source, 실제 인증/키/DB/백업 파일을 복사하지 않았다. 예시 주소192.0.2.1, operator와 demo-* 프로젝트명은 문서용 치환 값이다. 현재 코드는 특정 구성의 학습 사례이며 실제 배포 전 환경에 맞춰 검증한다.

시험 이동: 과거 설정 예제는 tests/fixtures에 둔다. 설치기의 원래 배포 위치 검사는 DEPLOYMENT_ROOT 상수로 유지했고 시험에서는 현재 checkout 위치로만 patch해 CI의 임시 경로에서도 합성 시험을 실행한다. 이 변경은 운영 원본에 적용하지 않았다.

원본 프레임워크 규칙 블록/스킬/라이선스는 그대로 보존했다. 공개 사본의 원격과 운영 원본의 조회 연결을 구분하며, 운영 main 이력을 공개 저장소로 직접 push하지 않는다.
