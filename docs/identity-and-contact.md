# 프로젝트 소유자와 연락처

- 현재 저장소: https://github.com/edubeom/smb-backup-lab
- 프로젝트 작성자 표시: edubeom
- 프로젝트 연락처와 새 Git 커밋 이메일: hello@edubeom.com
- 정본: config/project-identity.json

현재 운영 작업 폴더와 공개 사본의 Git 설정, 안내 문서, 강의와 시연 생성기는 이 정보를 사용한다. Git 설정은 이 두 프로젝트에만 적용한다. 서비스 설정과 운영 메일 계정은 이번 변경 대상이 아니다.

프레임워크 출처는 실제로 열리는 dev-process-light 원본과 고정 commit을 사용한다. 설치한 스킬/원본 라이선스와 저작권 고지, 기존 Git 커밋의 당시 작성자, 과거 단계의 source 사본/해시는 그 시점의 증거다. 현재 배포자의 연락처와 구분해 보존한다. 과거 문서의 SMB 링크는 현재 주소로 갱신했으며 당시 계정 인증·작성자에 대한 사실 기록은 유지한다.

교육 자료는 현재 주소와 연락처로 다시 생성하고 공개 GitHub 화면을 새로 촬영한다. 이전의 합성 시험 장면을 쓰는 경우 시험 시각과 원본 출력은 당시 값으로 남기고 새 시험처럼 표시하지 않는다.
