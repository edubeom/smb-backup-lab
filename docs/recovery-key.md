# 기존 암호화 복구 키를 G1 밖에 보관하기

**2026-10-20 16:06:37 KST 검증 통과.** 사용자가 외부에 보관했다고 확인한 기존 키를 숨김 재입력했고, 첫 성공본 `20261020T040000000000-1234abcd`의 공유기 암호화 명세를 그 키로 열었다. 기존 키 일치와 실제 복호화를 사용자 제공 JSON으로 확인했다. 외부 암호 관리자 자체를 에이전트가 검사한 것은 아니다. 값 없는 결과는 [검증 요약](../media/offsite-key-check.json)에 보존한다.

아래는 이후 재확인이 필요할 때의 절차다. 기존 키를 그대로 사용하며 새 키 생성/변경은 필요하지 않다. 이 검증으로 기존 백업 삭제나 timer를 활성화하지 않았다.

이 키는 **공유기 backup-user 비밀번호나 sudo 로그인 암호와 다르다.** `/etc/g1-backup/archive-passphrase` 파일의 내용이 백업을 여는 암호화 복구 키다. G1 밖의 PC/휴대폰에서도 접근 가능한 본인의 암호 관리자에 저장한다. 에이전트가 외부 서비스로 값을 보내거나 계정을 선택하지 않는다.

## 1. 개인 터미널에서 기존 키를 확인하고 보관

화면 녹화·화면 공유·자동 터미널 기록을 끈 **개인 G1 터미널에서만** 아래 읽기 명령을 직접 실행한다. 이 명령은 키를 그 개인 화면에 표시하므로 영상 촬영 중에는 실행하지 않는다. 에이전트 도구/채팅에서는 실행하지 않는다.

```bash
sudo cat -- /etc/g1-backup/archive-passphrase
```

한 줄 전체를 암호 관리자의 새 비밀 항목에 저장한다. 항목 이름은 `G1 백업 암호화 복구 키`처럼 정하고 비밀 값 칸에 넣는다. 안전 메모에는 UNC `\\192.0.2.1\backup\server\g1`, 파일 형식 GnuPG AES256/objects-v2, 복구 안내 위치를 함께 적으면 된다. SSH/공유기 비밀번호는 각각 별도로 관리한다.

키가 보이는 터미널 캡처나 암호 관리자 화면을 채팅·Git·유튜브에 넣지 않는다. 저장 후 암호 관리자를 잠갔다 다시 열어 항목이 남아 있고 G1 없이 접근 가능한지 확인한다. 키가 화면에 남은 터미널을 닫은 뒤 촬영을 재개한다.

## 2. 암호 관리자에서 다시 꺼낸 키로 실제 백업 열기

아래 도구는 키를 표시하지 않는다. 암호 관리자에서 **다시 복사한 키**를 숨김 입력창에 붙여넣는다. 명령 인자나 채팅에 키를 쓰지 않는다.

```bash
sudo python3 /project/smb-backup-lab/scripts/recovery_key.py \
  --verify-offsite --snapshot-id 20261020T040000000000-1234abcd
```

키를 외부에 보관한 뒤 거기서 다시 꺼내 입력하는 작업을 사용자 확인으로 기록한다. 도구는 입력 키가 기존 키와 같은지 비교하고, **재입력한 키로 공유기 암호화 명세를 실제 복호화**한다. 키·키 해시/지문·평문 명세는 출력하지 않는다. 틀린 키/손상된 명세면 확인 기록을 만들지 않는다. 원래 키와 백업을 변경하지 않고 임시 검증 복사본만 정리한다.

성공 결과의 `status=offsite-key-readback-and-shared-manifest-verified` 및 `shared_encrypted_manifest_decrypted_with_readback_key=true`를 확인한다. 결과에는 키 값이 없으므로 **마지막 JSON만** 채팅에 알려 주면 된다. 사용한 암호 관리자나 외부 보관 장소를 에이전트가 직접 검사한 것은 아니어서 `offsite_provider_independently_inspected=false`로 남긴다.

root 전용 `/var/lib/g1-backup/work/offsite-key-verification.json`에는 ID·시각·성공 상태와 사용자의 외부 보관 확인만 기록한다. 이 검증으로 timer/삭제 정책을 자동 활성화하지 않는다.

키를 외부에 보관하기 어려우면 아직 완료됐다고 표시하지 않는다. 현재 백업은 그대로 유지되며 별도 저장 방법을 정할 때까지 외부 보관 미완료로 남긴다.
